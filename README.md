# make-knowledge-cards

把用户粘贴的文章正文或本地 Markdown / TXT 文件，转换成 **5-8 张知识卡片**的开源 Skill。每张卡片只讲一个知识点，结构统一为「标题、核心知识、简明解释、例子或自测问题」，适合复习、整理与自测。

## 项目解决什么问题

长文章信息密度高、结构松散，直接阅读很难抓住重点、留存率低，复习时还要重新翻原文。本项目把文章自动提炼成一张卡片只讲一个知识点、结构统一的学习卡片，让你快速抓住核心、便于回顾与自测，且保证内容严格忠实原文、不注水不凑数。

## 主要功能

- **多输入**：接受对话中粘贴的文章正文，或本地 `.md` / `.txt` 文件。
- **结构化输出**：5-8 张卡片，每张含「标题、核心知识、简明解释、例子或自测问题」。
- **质量规则**：
  - 只提炼真正重要的知识，略去铺垫与修辞。
  - 一张卡片只讲一个知识点，不拆分、不合并。
  - 自动去重，删除重复或语义重叠的内容。
  - 不编造原文没有的信息，数字与结论忠实原文。
  - 知识点不足 5 个时按实际数量输出，绝不强行凑数；超过 8 个时保留最重要的 8 个。
  - 输出语言与原文一致（中文原文出中文，英文原文出英文）。
- **暂不支持**：网页抓取、PDF 解析、Anki 导出、图形界面。

## 安装方法

本 Skill 是供 AI Agent 加载的文件夹，无需编译或依赖安装，按你的 Agent 环境二选一：

- **方式一（读取 SKILL.md，通用）**：把 `skills/make-knowledge-cards/` 整个文件夹复制到你的 Agent 环境的 Skill 目录（如 `workspace/.user_skills/`、`~/.agents/skills/`）即可。
- **方式二（OpenAI Agents SDK）**：在 `agents/openai.yaml` 所在目录运行 `agents init`（或在现有 agent 配置中引用该 `openai.yaml`），SDK 会自动读取 `name` / `description` / `instructions` 注册技能。

> 可选验证：本仓库已通过官方校验脚本。
> ```bash
> python <skill-creator>/scripts/quick_validate.py skills/make-knowledge-cards
> # 输出：Skill is valid!
> ```

## 使用方法

1. 把 Skill 加载到支持 Skill 的 AI Agent 环境（见上文安装方法）。
2. 直接粘贴文章正文，或上传本地 `.md` / `.txt` 文件。
3. 使用触发话术，例如：
   - "把这段文章做成知识卡片"
   - "把这个文件转成知识点卡片"
   - "提炼这篇文章的知识卡片，用于复习"

## 输入输出示例

**输入（文章片段）**

> 归并排序采用分治思想，把数组不断对半切分到单元素，再两两合并有序。它的时间复杂度稳定为 O(n log n)，无论最好最坏都是这个量级，但需要 O(n) 的额外空间。

**输出（知识卡片）**

```
### 卡片 1｜归并排序的分治思想
- 核心知识：归并排序把数组递归对半切分到单元素，再逐层合并，属于典型的分治算法。
- 简明解释：分治分三步——分解（把数组切成两半）、解决（递归排序两半）、合并（把两个有序子数组合并成一个有序数组）。对半切分直到只剩一个元素（天然有序），再自底向上两两合并，最终得到整体有序序列。
- 例子或自测问题：对数组 [5,2,4,6,1,3]，第一刀如何切分？两个子数组分别排好后如何合并？
```
